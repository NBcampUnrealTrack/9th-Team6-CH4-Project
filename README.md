# 9th-Team6-CH4-Project

🃏 [프로젝트 이름 : The Operate]
언리얼 엔진 5.8 기반의 멀티플레이어 수학 카드 추리 게임입니다.

1. 프로젝트 개요 (Overview)장르: 수학 카드 추리 멀티플레이어 게임플레이 
인원: 4 ~ 6인

엔진 버전: Unreal Engine 5.8개발 

인원: 5인 (팀 프로젝트)

지원 플랫폼: PC (온라인 멀티플레이, 로컬 미지원)

2. 게임 규칙 및 플레이 방법 (How to Play)

목표: 자신의 카드(오픈됨)를 제외한 다른 플레이어들의 카드 숫자를 유추하여 수학 식을 모두 맞추면 점수를 획득합니다.

조작법: 오직 마우스 클릭만으로 게임 내 모든 상호작용(카드 선택, 버튼 클릭 등)이 가능합니다.

3. 기술 스택 및 아키텍처 (Tech Stack & Architecture)언어 & 스크립트: C++, Blueprint 병행
